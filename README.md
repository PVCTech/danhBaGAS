# danhBaGAS
Phiên bản danh bạ chạy trực tiếp trên google sheet

## Tính năng:
- Tìm kiếm cực kỳ linh động theo (tên, đơn vị, địa chỉ, xưng hô, ...)
- Có thông báo ngày sinh nhật trong tháng

1. Ưu điểm:
- Không phụ thuộc vào host ngoài (google thì đằng nào cũng phụ thuộc rồi và cũng là danh bạ trên android)
- Có thể thương mại hóa với giá thành phù hợp

- Tốc độ không tốt bằng php
